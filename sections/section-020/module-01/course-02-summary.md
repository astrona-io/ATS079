# Summary

Incident response organizes work around impact, coordination and evidence. Platform failures can affect shared capabilities and several teams, while application failures may have a narrower owner. Mitigation restores acceptable service without requiring immediate complete cause analysis. Communication, controlled changes and preserved evidence support recovery. Follow-up work should improve the relevant capability and contract rather than merely add alerts or blame the user who first encountered the failure.
