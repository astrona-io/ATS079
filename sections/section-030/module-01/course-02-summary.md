# Summary

Interoperability connects build evidence, approved desired changes, agent evaluation and runtime outcomes. CI can publish artifacts and propose intent without holding every target credential. Notifications accelerate or report work but do not replace authoritative state. Observability explains the resulting population and failure boundary. Each integration needs limited authority, stable identifiers and recoverable error handling so a successful upstream event is not mistaken for complete delivery.
