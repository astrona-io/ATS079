# GitOps Basics and Workflows

This section covers gitOps Basics and Workflows. It develops managed Runtimes, Agents And Policy Boundaries through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains can include intermediate checkpoints before the final review.

## Learning Outcomes

- Identify runtime, agent and policy components of a GitOps-managed system.
- Explain management scope and bootstrap dependencies.
- Reason about identity, ownership and external systems.
