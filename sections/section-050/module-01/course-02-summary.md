# Summary

An Application binds a source and rendering contract to a destination under a project and synchronization policy. Revision, path, cluster and namespace identify different parts of that relationship.

Project restrictions and destination API authority complement each other rather than substitute for each other. Tracking and deletion behavior need explicit ownership so delivery scope and resource lifecycle remain understandable and bounded.
